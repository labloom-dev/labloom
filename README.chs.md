<h1 align="center">知织</h1>

<p align="center">知织为（wèi）知之。</p>

为科研工作者打造的一站式、全流程 AI 研究工作空间。

2026 秋《问题求解实战》学期项目。

## 功能

1. **订阅**：订阅研究资讯，追踪最新文献。
2. **阅读、批注与引用**：阅读文献、高亮和批注，在笔记中引用原文并通过链接回溯出处。
3. **知识库**：集中管理笔记、研究成果和文献，并建立它们之间的关联。
4. **AI 功能**：借助 AI 筛选和推荐订阅中的文献、总结和解读论文，以及管理知识库。

## 开发

### 环境要求

- Node.js 22.x 或更高版本
- pnpm
- Git

### 启动开发服务器

```shell
pnpm install
pnpm dev
```

### 打包应用

```shell
pnpm build
```
