# 知织系统概要设计答辩大纲

正片20页，含封面。发言按9分40秒编排，另留20秒用于翻页、停顿和指图，总时长10分钟。用一篇从订阅中发现的论文贯穿答辩。先交代它进入哪个工作区，再说明哪些包处理入库、哪些数据需要一起保存。
