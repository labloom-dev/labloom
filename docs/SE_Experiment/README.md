# 需求规格说明书大纲

报告：[知织（Labloom）需求规格说明书](知织（Labloom）需求规格说明书.docx)

- 2. 系统概述：功能需求、非功能需求、接口需求、应用环境。

- 4. 词汇表及其他：主要术语、评审记录。
