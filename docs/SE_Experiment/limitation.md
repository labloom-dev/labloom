# 第 11 周设计文档的提示与注意事项

## 工作范围与材料

- 本 fork 只维护文档。本次不修改、实现或修复应用代码，不更新依赖或数据库迁移。
- 设计报告为 0.1 初稿。体系结构、数据、接口、构件和界面描述的是课程版设计方案，不代表主项目已经采用同名接口、类、表或流程。
- 需求基线为 `11_3知织（Labloom）需求规格说明书_评审修订版.docx`，版本 1.3。主项目概要设计 1.2 用作设计参考，不能直接替代课程版需求。
- `设计文档_格式样本.docx` 和同名 PDF 是用户提供的模板。报告沿用八章结构、各节顺序、属性表、接口表和流程写法；销售业务、Java 技术栈以及样本中的教学提醒不进入报告。
- 正文中的说明性提示、阶段性限制、未验证事项和“某项材料不能当成另一项材料”等辨析统一放在本文件。报告中的界面反馈和失败处理属于系统设计内容。
- Markdown 为便于审阅的文本源；DOCX 为排版版本；PDF 为阅读和版面检查版本。修改后需同步三种格式及图源，避免内容分叉。

## 课程范围与主项目差异

| 项目 | 课程版要求 | 处理方式 |
| --- | --- | --- |
| 功能范围 | UC01～UC06 | 不增加同步块、任务日程、AI、应用内工作区切换、删除、备份恢复等功能 |
| 内容块归属 | 一个块属于一个页面 | 数据类图使用 NotePage 到 Block 的组合；主项目多位置共享块设计不直接沿用 |
| PDF 重复导入 | 独立文献及独立副本 | 每次生成新标识；不采用主项目文献判重合并流程 |
| 来源移除 | 保留条目、来源名称和已读状态 | 课程设计采用可空外键和名称快照；需要在后续主项目适配时单独核对 |
| 保存时点 | 停止输入满 1 秒触发，常规提交后 1 秒内完成 | 不混用概要设计中“停止输入到保存完成不超过 1 秒”的表述 |
| 检索范围 | 笔记标题正文、文献标题与作者／DOI、订阅标题摘要 | PDF 全文查找保留在阅读器内；不加入全局索引 |
| 元数据 | 文献作者与 DOI 可用于检索 | 课程版不提供编辑入口，新导入文献字段可为空；检索验收可使用预置数据 |
| 迁移保护副本 | 保护既有数据 | 属于内部可靠性机制，不等于新增用户工作区备份恢复功能 |

## 模型与实现的关系

- 四层架构表达调用责任；六个逻辑包表达职责分组；Electron 渲染进程、preload 和主进程表达运行位置。这些维度不能互相替代。
- 实体类承载数据和局部行为，数据库访问交给 DAO。课程需求分析中的持久化操作在设计阶段分配给 DAO，不能逐字照搬分析类操作作为实际实体职责。
- 报告中的 `window.labloom`、控制器、DAO、表名及方法签名是设计契约；现有主项目的 `window.api` 或其他接口必须以源代码为准。本 fork 不进行接口改名或迁移。
- 数据表是面向课程模型的设计，不是可直接应用于主项目数据库的迁移脚本。现有块共享、内置属性、页面类型等结构与本设计存在差异。
- UML 图按课程版模型绘制。图内主要路径和正文异常处理共同组成设计，不可只凭一张正常流程图宣称全部异常已覆盖。
- 所有性能数字均为需求目标或测量约定，不是实测结果。本次没有运行应用、构建、数据库迁移或功能测试。

## 待评审与待验证事项

1. 由小组评审四层调用结构与六包职责映射，确认控制器、DAO 和平台接口命名。
2. 校验全部六个用例与 FR/NFR、数据表、接口、顺序图的对应关系，重点检查来源移除保留、笔记保存批次、PDF 导入失败补偿。
3. 检索词项方案需验证中文短词、混合文本、候选集规模、首批延迟及结果快照内存；“前 50 条”不能掩盖生成完整快照的成本。检索性能目标尚未实测。
4. 整页块集合替换方案需验证基线保存时延、块标识保留和大型笔记行为。100 块／20 KB 是保存测量约定，不代表任意规模均达到同一时限。
5. 文件与 SQLite 事务不是跨资源原子事务。报告采用恢复记录、同盘发布和补偿清理；断电窗口、清理失败、恢复记录损坏、磁盘满需验证。
6. PDF 结构验证、加密文件识别、读取附件字节的内存峰值及损坏文件行为需在实际阅读库上验证。
7. 工作区锁需覆盖符号链接、路径大小写、PID 重用和异常退出；迁移还需校验 WAL 模式下保护副本的一致性。
8. 图中文字和排版已通过本地输出检查；提交前仍需在课程使用的 Word／WPS 环境确认分页和字体替换。
