| 页 | 标题 | 画面与讲解要点 | 用时 |

### 第17页指标表

| 项目 | 条件 | 验收目标 |
| --- | --- | --- |
| 编辑与保存 | 常规交互、编辑停止后 | 交互反馈P95≤100ms，停止输入后自动保存≤1秒 |
| 启动与大页 | 应用冷启动、单个一万块页面连续滚动 | 冷启动≤5秒，大页滚动帧率P5≥30fps |
| 全文检索 | 本地索引已就绪 | 首批结果P95≤1秒 |
| PDF阅读 | 本地PDF共100页且文件大小≤50MB | 首屏≤3秒 |
| 提醒 | 应用运行期间 | 触发时间偏差≤2秒 |
| 空闲资源占用 | 打开10个普通标签页后空闲 | 内存≤1.5GB，1分钟平均CPU占用≤单核5% |

讲解时区分两个规模。一万块用于单个大页面的滚动验收，十万块是整个工作区的容量基准。详细设计阶段用一万块原型验证编辑与滚动，用中文短词和中英文混排语料验证检索效果。

## 制图与时间安排

- 第3页按渲染进程、受限preload和主进程安排技术栈，工作区数据库与附件目录标在实际访问的一侧。
- 第4页只画源码依赖。第5至10页每页只展开一个顶层包，使用相同的包名和编号，分别说明内部职责、公开接口和依赖边界。
- 第11页将全局E-R图重排为横屏，保留主干实体、联系名称和基数。第12至16页依次展开图7.2至图7.6，沿用矩形实体、菱形联系、椭圆属性的记法。
- 第3页结束约1分10秒，第10页结束约5分钟，第16页结束约8分50秒，性能要求讲完约9分40秒。
