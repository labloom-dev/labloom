# 知织前端改版与功能实现

核查日期：2026-11-06。本次继续完成可日常使用的主要流程，采用参考设计的卡通暖纸视觉，保持 Labloom 的 Electron、Svelte 5、TypeScript、bits-ui 结构。界面文案不再使用中间点作分隔符。

## 已接通的功能

| 领域 | 本次实现 |
| --- | --- |
| 页面与编辑 | SQLite 持久化页面、标题与富文本，650 ms 自动保存，保存状态、错误重试、版本冲突检查与另存副本。支持标题、列表、引述、代码、图片、网址、表格行列编辑、块移动和撤销重做。关闭页面先保存，关闭应用时对未保存内容提示。 |
| 知识组织 | 笔记、文献、批注、任务、日程统一列表；共享标签、自定义文本/数字/勾选/日期属性，标签和属性组合筛选，批量标签、属性、固定和独立保留操作。全局搜索覆盖标题、正文、属性和订阅摘要。 |
| 内容关联 | 页面和顶层内容块引用，只读或可写同步，反向链接，解除链接保留副本，循环展开保护。非独立页面在无法由有效独立页面抵达时进入回收站，恢复后独立保留。 |
| 文献 | Feed 入库、本地 PDF、DOI 和 BibTeX 导入，基本去重、失败信息；作者、年份、来源、DOI、网址与摘要。阅读时尝试从 PDF 的 Title/Author 字段补充未填写的信息，不从创建时间推测发表年份。 |
| 阅读 | PDF 附件落盘，多版本分别保存，默认打开最新版本；跨会话阅读位置、缩放与旋转，文本搜索，高亮和区域标注，标注颜色与删除，独立批注页面及返回指定版本原文。 |
| 订阅 | 来源分组、暂停、自动刷新间隔、关键词偏好、日期/未读排序、批量已读、当前结果页内上一篇/下一篇，保留原有 RSS/Atom/arXiv/研究博客解析。自动刷新只在应用运行期间执行，暂停来源仍可手动单独刷新。 |
| 任务与日程 | 页面正文、任务状态、优先级、开始/截止时间、全天计划、时区、月历和列表，逾期判断、应用内提醒与重新打开后的未读提醒。日期截止按所选时区当天结束处理；夏令时中不存在的时间会提示修正。 |
| 工作区 | 带 SHA-256 清单的完整备份；校验数据库与所引用的 PDF；恢复至新的空文件夹后切换工作区，保留原工作区。恢复前保存编辑内容并等待订阅请求结束。空间占用、Markdown 和 BibTeX 导出。 |
| 应用体验 | 真实页面/文献/任务统计、最近访问、固定页面、导航前进后退、标签拖动、分栏及标签布局恢复；浅色/夜间/系统主题、阅读字号和动效偏好，设置保存在工作区。`Ctrl / ⌘ + K` 搜索，`Ctrl / ⌘ + S` 保存。 |
| AI | 可配置 Ollama 地址和模型，选择最多 10 个资料页面提问、摘要与解释，取消/超时/错误处理，来源入口，以及将回答和引用保存为知识页面。只有发送问题时才请求模型。可选令牌用 Electron safeStorage 保存，系统不支持安全存储时拒绝保存令牌。 |

AI 使用 [Ollama Chat API](https://docs.ollama.com/api/chat)。默认地址为 `http://localhost:11434`，模型名称由用户填写。更换服务地址时不会自动转移旧令牌；跨设备恢复后可能需要重新输入令牌。当前对话在应用会话中保留，需要长期保留的回答可保存为知识页面。

## 存储与实现边界

- 新增 schema v4，没有重写已发布的 v1、v2、v3。旧工作区仍按原机制在升级前生成数据库备份。v4 补充页面详情、标签、关联、附件、批注、访问记录、提醒与工作区设置。
- 富文本使用现有 Tiptap / ProseMirror。顶层块拥有稳定标识，复制内容会分配新标识，避免副本修改原块。共享编辑通过统一页面会话和乐观版本检查处理，不静默覆盖已经更新的页面。
- PDF 文件使用独立标识保存，内容以 SHA-256 检查重复；新版本保留旧文件及其标注。批注坐标使用 PDF 坐标，因此缩放和旋转不会改写原文位置。
- Markdown 导出包含选中页面可达的关联页面、图片和 PDF，最多 500 个页面；导出先写入临时目录，成功后完成目录重命名。文件名使用页面标识保持链接稳定，README 说明颜色和实时同步等不能保留的能力。需要恢复全部状态时应使用工作区备份。
- 备份恢复不覆盖当前工作区。校验失败会保留原数据，并清理此次创建的恢复临时目录。备份包含设置，但不包含未保存的内存对话。
- 新增 `main/knowledge`、`main/assistant` 和 `renderer/components/Knowledge`，继续使用明确的 shared API 与 preload IPC 边界，没有新增运行时依赖。

## 仍未覆盖的高级需求

以下条目仍需后续实现，不能把本次主要流程交付等同于所有 `LB-USR-*` 条目的完整验收：

- 文献版本的内容差异比较、批注候选定位和迁移、按版本独立保存完整书目信息、补充附件，以及重复导入时的交互式合并选择。当前保留各版本和原始批注位置，不自动迁移。
- Feed 富文本图片正文、Feed 原文区域批注与阅读位置恢复。当前提供来源摘要；文献入库后可附加 PDF 并标注。
- 任意深度块作为独立共享目标、行内引用与预览尺寸切换、正文中的动态筛选列表、固定标签/筛选视图，以及按草稿链接自动生成参考文献清单。
- 自定义选择型属性、属性级显示偏好、文献来源元数据与个人修订的分层只读模型、导出前逐项选择关联范围。
- BibTeX 宏和跨条目继承的完整兼容、单个文件里语法损坏条目的独立容错。当前支持常见条目和嵌套花括号；语法解析失败会显示错误。
- 总览组件配置、完整界面语言切换和全局界面字号。当前实现正文阅读字号。
- AI 全库语义检索、自动推荐及更多模型协议。当前是用户明确选择资料后的上下文问答，PDF 不进行 OCR 或自动全文提取。

## 本地复现与审阅

安装 Node.js 22.12 或更高版本与 pnpm，在项目根目录执行：

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm test:feed
pnpm test:knowledge
pnpm test:workspace
pnpm dev
```

`pnpm dev` 启动 Electron，需要桌面显示环境及 Electron 的系统依赖。首次运行时选择新的空文件夹建立审阅用工作区，再尝试新建笔记、重开后检查保存、导入 PDF、添加批注、创建任务和备份恢复。原有 `pnpm dev:feed` 只提供独立订阅预览，不是完整应用入口。本机试用桥接脚本、演示数据和构建产物没有提交。

建议重点审阅 schema v4 升级、页面保存冲突与关联生命周期、PDF 附件及备份校验、工作区切换时的异步请求，以及 renderer / preload / main 的接口边界。高级功能缺口见上文；真实模型、原生文件对话框与各平台窗口行为需要在审阅设备上验证。
