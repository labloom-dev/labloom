# 板块 2：文献管理

LB-USR-2-1：用户可从 Feed 条目将文献导入文献库，并保留来源提供的标题、作者、摘要、发布时间和原文网址。

LB-USR-2-2：用户可导入本地 PDF 文件，系统应尝试获取文献元数据；未能获取元数据时，仍可保留并阅读该文件。

LB-USR-2-3：用户可通过 DOI 等文献标识符获取并导入文献的书目信息；来源提供可获取的全文时，可一并导入。

LB-USR-2-4：用户可导入 BibTeX 文件，批量添加文献。

LB-USR-2-5：导入完成后，用户可查看成功和失败的条目及失败原因；失败条目不应影响已成功导入的内容，并可重新尝试导入。

LB-USR-2-6：导入疑似重复文献时，系统应提示已有文献，由用户选择使用已有文献、作为其新版本导入或仍然新增文献。

LB-USR-2-7：文献应作为知识库中的特殊页面供用户独立打开、搜索、打标签及在其他页面中使用链接，其通用页面操作遵循板块 3 的规则。

LB-USR-2-8：用户可查看来源提供的标题、作者及其顺序、文献类型、发表时间、期刊或会议名称、卷期、页码、摘要、关键词、DOI 和原文网址等书目信息。

LB-USR-2-9：来源未提供的书目信息应明确显示为缺失；用户可重新获取来源信息，系统不应以推测内容填充缺失字段。

LB-USR-2-10：书目信息应作为文献页面专属的内置属性，用户可选择显示或隐藏，普通页面不应因此具有作者、DOI 等文献专属属性。

LB-USR-2-11：文献原文和来源书目信息应只读；用户仍可编辑文献页面的个人标签、自定义属性及独立性设置。

LB-USR-2-12：用户可将文献独立保存到文献库，也可在普通页面中导入非独立文献并插入其链接；文献的保留和删除遵循板块 3 的页面独立性规则。

LB-USR-2-13：文献库应集中展示知识库中的文献页面，默认展示独立保存的文献；用户也可查找非独立文献，查看使用它的页面，并将其转为独立保存。

LB-USR-2-14：用户可按标题、作者、关键词或 DOI 搜索文献，并按文献类型、发表时间、个人标签或自定义属性筛选结果。

LB-USR-2-15：用户可按标题、发表时间或导入时间排列文献，并对选中文献批量设置个人标签、调整独立性、导出或删除。

LB-USR-2-16：同一文献可包含多个版本，用户可查看版本列表、版本标识和来源信息，并打开指定版本。

LB-USR-2-17：用户未指定版本直接打开文献，或使用未指定版本的文献页面链接时，应默认抵达最新版本，并能看见当前版本标识。

LB-USR-2-18：用户可创建指向指定文献版本的引用或同步链接；新增版本后，该链接仍应呈现原先指定的版本，并在用户打开目标时抵达该版本。

LB-USR-2-19：用户导入新版本时，系统应保留已有版本及其相关内容，不应直接覆盖旧版本。

LB-USR-2-20：用户可比较同一文献不同版本的内容差异，并查看各版本对应的批注；批注定位与迁移遵循板块 3 的规则。

LB-USR-2-21：用户可查看各版本的 PDF 及补充附件，添加附件时应能指定其对应版本。

LB-USR-2-22：用户可按与普通页面一致的页面浏览方式，独立打开文献页面，或在普通页面中通过引用或只读同步阅读文献内容；原文中的文字片段、图表或页面区域可作为链接目标，保留对应文献、版本和位置。

LB-USR-2-23：用户可在文献页面中查看相关的批注页面、笔记页面及其他使用该文献的页面，并打开相应内容。

LB-USR-2-24：用户可访问文献的原文网址；全文或附件无法打开时，系统应提示原因，并保留已有文献记录及可用内容。

LB-USR-2-25：用户可将选定文献、当前筛选结果或全部独立文献导出为 BibTeX 文件；未指定版本时应使用最新版本的书目信息，也可选择导出指定版本的信息。
