# 板块 1：Feed 抓取

LB-USR-1-1：用户可通过输入 RSS 或 Atom 订阅地址，添加关注的论文动态或行业资讯来源。

LB-USR-1-2：用户添加订阅来源时，系统应检查地址是否有效；无法订阅时，应提示失败原因。

LB-USR-1-3：用户可查看已添加的订阅来源，并修改来源名称和订阅地址。

LB-USR-1-4：用户可创建、重命名和删除订阅分组，并将订阅来源移入或移出分组。

LB-USR-1-5：用户可暂停或恢复指定来源的内容抓取，也可取消订阅该来源。

LB-USR-1-6：用户可手动刷新指定来源或全部已启用的来源，获取最新内容。

LB-USR-1-7：用户可启用或关闭自动刷新，并设置自动刷新的时间间隔。

LB-USR-1-8：用户可查看各订阅来源的抓取状态、最后成功刷新时间和本次新增条目数量。

LB-USR-1-9：来源抓取失败时，系统应提示失败原因并允许用户重试，保留已获取的内容，且不影响其他来源的正常抓取。

LB-USR-1-10：同一来源多次抓取到同一条内容时，系统不应重复添加该条目，并应保留其已有的阅读状态。

LB-USR-1-11：用户可集中浏览全部来源的内容，也可按订阅来源或分组查看内容列表。

LB-USR-1-12：用户可在内容列表中查看条目的标题、来源，以及来源提供的作者、发布时间和摘要。

LB-USR-1-13：用户可设置关注关键词，并按关键词筛选已获取的论文动态和行业资讯。

LB-USR-1-14：用户可通过关键词搜索已获取条目的标题和摘要。

LB-USR-1-15：用户可按发布时间由新到旧或由旧到新排列内容；未提供发布时间的条目应明确标示。

LB-USR-1-16：用户可查看未读条目及其数量，并按已读或未读状态筛选内容。

LB-USR-1-17：用户可将单条内容标记为已读或未读，也可将指定来源或分组中的全部内容标记为已读。

LB-USR-1-18：用户可打开 Feed 条目，阅读来源提供的正文或摘要，并查看其中的图片和链接。

LB-USR-1-19：条目仅提供摘要时，系统应明确提示，用户可通过原文链接继续阅读完整内容。

LB-USR-1-20：用户可从条目列表或条目内容打开原始来源页面。

LB-USR-1-21：用户阅读 Feed 条目时，可调整正文显示的字体大小；主题设置遵循板块 4 的规则。

LB-USR-1-22：用户从列表打开条目后，可切换当前列表的上一篇或下一篇内容。

LB-USR-1-23：用户可从文献库或普通页面中的文献链接打开文献页面，并在页面中阅读对应版本的原文及已关联的 PDF 附件。

LB-USR-1-24：用户在文献页面中阅读 PDF 时，可翻页、跳转到指定页码，并放大、缩小或按页面宽度显示文档。

LB-USR-1-25：用户可在文献页面中对含有可检索文本的 PDF 查找关键词，并跳转到匹配位置。

LB-USR-1-26：系统应保存用户的阅读位置，用户再次打开同一 Feed 条目或同一版本的文献时，可从上次的位置继续阅读；文献阅读位置应按版本分别保存，不应改变板块 2 的版本选择规则。

LB-USR-1-27：内容或 PDF 无法打开时，系统应提示原因，并在存在原文链接时提供原文访问入口。

LB-USR-1-28：用户可在浏览或阅读条目时，将感兴趣的文献加入文献库，并可查看该文献是否已经入库。

LB-USR-1-29：用户重新打开应用后，可继续查看已保存的订阅来源、分组、已获取内容和阅读状态。
